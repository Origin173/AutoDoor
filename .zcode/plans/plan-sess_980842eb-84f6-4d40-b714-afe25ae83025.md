# PZ B42 自动门遥控器 Mod（AutoDoorRemote）

## 目标
新增一套 mod 专属的**可建造自动门**（不改动原版门）：车库门 3 款 + 栅栏门 3 款。每扇门建造时自动生成**专属遥控器+钥匙**；背包里有遥控器时按 K 键（可改键）即可在车内远程开关门，锁着的门若持有钥匙自动解锁再开。

## 已验证的技术基础（B42.20.2 本地验证）
- 门 = `IsoDoor` 对象；sprite tile 属性识别：`GarageDoor = 1`（车库门，`walls_garage_01_51` 等）、`doorW/doorN/doorTrans`（栅栏门，`fixtures_doors_fences_01_128` 等）
- 老式 `ISBuildingObject` 流程在 B42 完整保留：右键菜单 → `getCell():setDrag()` → `ISBuildAction:perform()` 服务端调 `item:create(x,y,z,north,sprite)`（`client/BuildingObjects/TimedActions/ISBuildAction.lua:229`）；活跃 B42 mod GreggiesGarageDoors 用此路线
- 钥匙配对：物品原生 `KeyId` 字段（`setKeyId/getKeyId`，跨端自动同步）+ `IsoDoor:checkKeyId()` + 背包 `haveThisKeyId()`；Doorknob keyId 转移是 vanilla 机制
- 按键：B42 无 ISKeyBindings；注册进全局 `keyBinding` 表（显示在"选项→按键"，默认 K——唯一空闲字母键），`Events.OnKeyStartPressed`（按下边沿触发）+ `getCore():isKey()` 过滤（支持改键）
- 开合：`door:ToggleDoor(player)`（native，含动画/音效/同步）；解锁：`setLockedByKey(false)` + `syncIsoObject(false,0,nil,nil)`（vanilla ISLockDoor 模式）；车库门多格链：`IsoDoor.getGarageDoorPrev/Next` 原生遍历（Lua 版 `buildUtil.getGarageDoorObjects` 在 server 端，客户端不可用，需自实现）
- 音效：复用原版 `GarageDoorOpen/Close`（ToggleDoor 自动播）、`DoorIsLocked`、`playUISound("UIActivateButton")`

## 实现要点

### 1. 物品（items_AutoDoor.txt）
- `RemoteDoorOpener`：Electronics，`WorldStaticModel = RemoteController`（复用原版），重量 0.3
- `AutoDoorKey`：`ItemType = base:key`（钥匙类型，KeyId 运行时绑定）

### 2. 门构建类（shared，核心）
- `ISAutoGarageDoor`：3 tile 车库门（复用原版 sprite 集 `walls_garage_01/02_*`，具体 tile 组合实现时从 newtiledefinitions.tiles.txt 确认）。`create()` 中：生成 `keyId = ZombRand(100000,999999)` → 每 tile `IsoDoor.new(cell, square, sprite, north)` + `setKeyId` + `ModData.autoDoor = true` + `AddSpecialObject` → 消耗材料 → 背包生成遥控器+钥匙并绑定 keyId
- `ISAutoFenceGate`：单 tile 栅栏门（金属网 `fixtures_doors_fences_01_128-131` / 金属杆 / 木栅栏，实现时确认 sprite），同样逻辑
- `isValid`：技能/材料/目标格检查；`render`：ghost 预览（参考 GreggiesGarageDoors）

### 3. 建造菜单（client）
- 右键地面 → "建造自动门" 子菜单：车库门 3 款（灰卷帘/白卷帘/带窗卷帘）、栅栏门 3 款（金属网/金属杆/木栅栏）
- 材料/技能/工具检查（锤子/喷灯、木工/焊接等级），不满足置灰
- 成本参考原版：车库门=木板8+钉子8+铰链4+门把手2+螺丝8+金属板4（木工6）；金属网栅栏门=喷灯+金属管3+铰链2+废金属4（焊接3）；木栅栏门=木板4+钉子4+铰链2+门把手1（木工3）

### 4. 遥控逻辑（client）
- 按键处理：`getCore():isKey("Open Door With Remote", key)` → `FindItem("Base.RemoteDoorOpener")`（背包即有效）→ 锚点取车辆位置（`getVehicle():getSquare()`，车内可远程）→ 半径 12 格搜 `getObjects()` 中 `instanceof IsoDoor` 且 `ModData.autoDoor` → 选 keyId 匹配的最近一扇
- 锁定处理：`isLockedByKey()` 且背包 `haveThisKeyId()` → 先解锁（链上所有 parts `setLockedByKey(false)+syncIsoObject`）再开；无钥匙 → 播 `DoorIsLocked` 音效
- 开合：`ToggleDoor`；车库门对链锚点调用（native 联动），另加链上状态校验兜底
- 右键遥控器物品菜单也加"打开/关闭门"选项（双通道，方便下车后使用）

### 5. 翻译与图标
- EN/CN JSON：物品名（遥控器/自动门钥匙）、按键名、6 款门名、建造菜单文案
- 图标用纯 Python 程序绘制（PIL 不可用则手写 PNG），保证 128x128 清晰可辨
