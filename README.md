# AutoDoorRemote 自动门遥控器 (Project Zomboid B42)

把原版**车库门**和**围墙栅栏门**变成遥控自动门：用电子材料做出**遥控器**和**自动门电机**（信号接收器+电机一体机，需装电池），给门安装配对后，把遥控器放背包里，坐在车里按 **K** 即可远程开关门，**无需下车**。门的外观、大小、贴图和开合动画**完全保持原版**——本 mod 不替换门对象、不修改原版文件。

## 功能
- **安装式替换**：对未上锁的原版车库门（含 3 格卷帘整扇联动）、围墙栅栏门（含双扇大门）或玩家自建门右键 → **安装自动开门器**
- **两件套设备**：遥控器发信号（电学 1 级制作）；自动门电机（信号接收器+电机一体机）负责实际开关门（电学 4 级：电子废料×3 + 电线×2 + 螺丝×2 + 无线电接收器）
- **电机放在门旁的地上**：安装时电机作为地面物品放置到门旁的空地（紧贴门/墙），不再被消耗；可随时捡起，捡走后该门断电——想换位置就把电机捡起来装到另一扇门
- **自动门杂志**：阅读后解锁两个配方（`NeedToBeLearn`）；杂志在邮箱等容器中刷新
- **需要电池**：安装消耗 1 个电池（首块电池）；每次开关门耗电 0.5（满电 100 ≈ 200 次）；耗尽后右键门 → **更换电池**
- **一把遥控器配多扇门**：可重新配对（换遥控器）或移除开门器（解除配对，电机留在地上可捡走）
- **车内远程**：驾驶座上按 **句号键 .**（默认键，可在 选项→按键 中改），以车辆为中心 12 格半径搜索
- **不绕过门锁**：上锁的门无法安装，遥控器对已锁的门不响应

## 安装
1. 把 `mod.info`、`poster.png`、`42/` 放入 `C:\Users\<用户名>\Zomboid\mods\AutoDoorRemote\`（B42 只识别 `Zomboid\mods\` 与 `Zomboid\Workshop\` 两个目录）
2. 启动游戏 → 主菜单 **Mods** → 勾选 `Auto Door Remote`

## 使用
1. 找到**自动门杂志**并阅读，学会配方
2. 电学 1 级做**遥控器**（电子废料×2 + 电线×2 + 螺丝刀）；电学 4 级做**自动门电机**；再准备 1 个**电池**
3. 走到未上锁的门前，右键门 → **安装自动开门器**（电机放置到门旁地面，消耗 1 个电池，自动配对背包里的遥控器）
4. 坐在驾驶座，遥控器放背包 → 按 **句号键 .** 开关门
5. 管理：右键已安装的门 → 自动开门器 → **重新配对** / **更换电池** / **移除自动开门器**

## 文件结构（B42 标准布局）
```
mod.info                    # 根 mod.info（游戏靠它识别 mod）
poster.png                  # 模组海报
42/                         # 版本文件夹（B42 必需）
├── mod.info
└── media/
    ├── scripts/            # items_AutoDoor.txt 物品定义；recipes_AutoDoor.txt 配方
    ├── textures/           # 物品图标 Item_*.png
    └── lua/
        ├── shared/AutoDoor/AutoDoorDoorLib.lua        # 门识别/联动/配对/电量共享库
        ├── shared/Translate/{EN,CN}/*.json            # 翻译（vanilla 同名文件，按键合并）
        ├── server/AutoDoor/AutoDoorDistribution.lua   # 杂志战利品（邮箱）
        └── client/AutoDoor/                           # 安装菜单 / 遥控逻辑 / 按键
```

## 开发
- `node tools/check_lua.js` — Lua/JSON 结构自检（发布前运行）
- 设计要点：安装只给门写 ModData 标记（`autoDoor`、`remoteKeyId`、`motorCharge`、`motorX/Y/Z`），门本身仍是原版 `IsoDoor`；电机以地面物品形式放置（`AddWorldInventoryItem`，引擎自动同步）；安装/换电池/卸载走服务器命令（`OnClientCommand`），MP 与 SP 一致

## 已知限制
- 深度联机并发（双人同时配对同一把遥控器）未做特殊处理
- 若第三方翻译 mod 覆盖了本 mod 的文案键，物品名可能显示英文原名
