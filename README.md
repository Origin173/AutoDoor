# AutoDoorRemote 自动门遥控器 (Project Zomboid B42)

建造属于你自己的自动车库门和自动栅栏门，每扇门配套专属**遥控器 + 钥匙**。
把遥控器放在背包里，按 **K**（可在 选项→按键 中更改）即可**在车内远程**开关门，无需下车。
门锁着时，背包里持有匹配钥匙会自动解锁再开。

## 功能
- **6 款自动门**（不修改原版任何门）：
  - 自动车库门 3 款：灰色卷帘 / 白色卷帘 / 白色面板（3 格宽卷帘门，原版素材）
  - 自动栅栏门 3 款：金属网 / 金属杆 / 木栅栏（单格，原版素材）
- **一对一配对**：建造时自动生成专属遥控器和钥匙（掉进背包），只有这把遥控器能开这扇门
- **车内远程**：驾驶座上按 K 即可开关门（以车辆位置为搜索中心，半径 12 格）
- **自动解锁**：门已上锁且背包有匹配钥匙 → 先解锁再开；无钥匙 → 播放"已上锁"提示音
- 多格车库门按整扇处理（原生卷帘动画）

## 安装 / 启用
1. 开发目录：`D:\Code\autodoor\`（本仓库根）
2. 已部署到本地 mods：`C:\Users\Origin\Zomboid\mods\AutoDoorRemote\`
3. 启动游戏 → 主菜单 **Mods** → 勾选 `Auto Door Remote` → 新建/加载存档
   （旧存档可在 载入→更多… 中给存档启用 mod）

## 建造方法
1. 背包里有**锤子**，地面右键 → **建造自动门** → 选择款式
2. 幽灵预览变绿后左键放置，动画完成即建成，遥控器和钥匙自动进入背包
3. 材料与技能（材料可放背包或附近地面）：
   - 车库门（木工 6）：木板×8 钉子×8 铰链×4 螺丝×8 金属板×4
   - 金属网门（焊接 3）：金属管×3 铰链×2 废金属×4 螺丝×2
   - 金属杆门（焊接 4）：金属管×6 铰链×2 废金属×6 螺丝×2
   - 木栅栏门（木工 3）：木板×4 钉子×4 铰链×2 门把手×1

## 使用方法
- **车内**：坐在驾驶座，背包里任意位置有遥控器 → 按 K（默认键）
- **车外**：右键背包里的遥控器 → 打开/关闭门（也可按 K）
- 门的状态切换：关着→开，开着→关
- 锁定：右键门 → 锁定（需要钥匙，室内无需钥匙）后，只有持匹配钥匙的遥控器能开

## 已知限制 / 风险
- **MP 联机**：已支持纯客户端（非主机）建造。客户端通过 `require` 加载服务端
  构建类（vanilla 同款机制，见 `ISAnimalContextMenu` 先例），建造走 B42 原生
  build action 事务，由服务端执行 `create()` 并同步全服；开关门走原生同步。
  若某版本 require 失败，建造菜单自动隐藏（不影响遥控功能）。
- **翻译**：中英文案随包附带；若 B42 未加载 mod 翻译文件，物品名会显示英文原名，
  功能不受影响。
- 车库门的"链式联动"依赖原版 native 处理；若个别版本不联动，会退回单格独立开关
  （后续版本处理）。
- 与车辆同行测试注意：放置时门洞方向按鼠标相对位置（R 键旋转），车库门 3 格
  需要连续 3 格无碰撞。
