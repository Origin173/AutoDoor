# AutoDoorRemote 自动门遥控器 (Project Zomboid B42)

把**原版车库门和围墙栅栏门**变成遥控自动门。用电子材料做出**遥控器**（发信号）和
**自动门电机**（信号接收器+电机一体机，装电池、负责实际开关门）；给门安装电机并
配对后，把遥控器放在背包里，坐在车里按 **K**（可在 选项→按键 中更改）即可**远程
开关门，无需下车**。门的外观、大小、贴图和开合动画**完全保持原版**——本 mod 不替换
门对象、不修改原版任何文件。

## 功能
- **替换原版门（安装式）**：世界里任何**未上锁的**原版车库门（`walls_garage_*`，含 3 格
  卷帘门整扇联动）、围墙栅栏门（`fixtures_doors_fences_01_*`，含单扇门和双扇大门）以及
  **玩家自建的门**（木工/焊接造的木门、双开门等，原版自建门带 `need:` 材料标记）都可以
  右键 → **安装自动开门器**，安装后即可遥控
- **两件套设备（更真实）**：
  - **遥控器**：负责发送信号（电学 1 级制作）
  - **自动门电机**（信号接收器+电机）：安装在门上，负责实际开关门
    （电学 4 级制作：电子废料×3 + 电线×2 + 螺丝×2 + 无线电接收器）
- **自动门杂志**：**阅读后解锁**遥控器和电机的制作配方（配方改为
  `NeedToBeLearn`，未读杂志前制作菜单里是灰色）；杂志会在**邮箱**等
  容器中刷新（也可用 debug 菜单直接获得）
- **需要电池**：安装时消耗 1 个电机 + 1 个电池（首块电池）；**每次开关门消耗
  0.5 点电量**（满电 100 点 ≈ 200 次开关）；电量耗尽后遥控器只响不动作，
  右键门 → **更换电池**（消耗 1 个电池，充满）
- **一把遥控器配多扇门**：同一把遥控器可以对基地所有门配对；右键门可
  **重新配对**（换一把遥控器）或 **移除自动开门器**（恢复成普通原版门）
- **车内远程**：驾驶座上按 K 即可开关门（以车辆位置为搜索中心，半径 12 格）
- **遥控器只发信号**：**只能给未上锁的门安装**（上锁的门选项置灰），遥控器
  **不绕过门锁**——门被锁上后按 K 不响应（播放"已上锁"提示音）
- 多格车库门 / 双扇大门按整扇处理（原生链式动画与同步）

## 安装 / 启用
1. 开发目录：`D:\Code\autodoor\`（本仓库根，B42 标准结构：`42/` 版本文件夹）
2. 已部署到本地 mods：`C:\Users\Origin\Zomboid\mods\AutoDoorRemote\`
3. 启动游戏 → 主菜单 **Mods** → 勾选 `Auto Door Remote` → 新建/加载存档
   （旧存档可在 载入→更多… 中给存档启用 mod）

## 使用方法
1. **读杂志**：在邮箱/书架上找到**自动门杂志**，阅读后学会配方
   （debug 模式下可右键门 → "调试: 生成配对遥控器" 直接获得遥控器+杂志）
2. **做设备**：电学 1 级做**遥控器**（电子废料×2+电线×2+螺丝刀）；电学 4 级做
   **自动门电机**（电子废料×3+电线×2+螺丝×2+无线电接收器+螺丝刀）；再准备 1 个**电池**
2. **安装配对**：走到一扇未上锁的原版车库门/栅栏门前，右键门 → **安装自动开门器**
   （消耗电机+电池，自动配对背包里的遥控器；三样缺一选项置灰）
3. **车内使用**：坐在驾驶座，遥控器放在背包里 → 按 **K**（默认键，可改键）
4. **管理**：右键已安装的门 → 自动开门器 → **重新配对遥控器** / **更换电池** / **移除自动开门器**

## 设计说明
- **不替换门对象**：安装只是给门打上配对标记（ModData），门本身还是原版 `IsoDoor`，
  贴图、尺寸、碰撞、开合动画（卷帘升起/门扇摆动）和声音全部是原版
- **配对原理**：遥控器首次配对时生成唯一编号，写入遥控器 ModData 并同步到门（多格
  门的每一格都写入）；按 K 时以车辆为中心在 12 格半径内找"编号匹配"的最近一扇门
- **电量存储**：电机电量存在门的 ModData（`motorCharge`，满 100）；每次开关 -1，
  右键门"更换电池"消耗 1 个 `Base.Battery` 充满

## 已知限制 / 风险
- **配方加载**：配方文件位于 `media/scripts/recipes_AutoDoor.txt`（B42 新
  `craftRecipe` 格式，参照 vanilla `recipes_radio.txt` 与活跃 B42 mod）。若个别 B42
  版本未加载该路径的配方，物品定义仍在，可手工 `additem RemoteDoorOpener` 验证其余
  功能；配方路径问题只需移动文件位置。
- **翻译**：中英文案随包附带；若 B42 未加载 mod 翻译文件，物品名会显示英文原名，
  功能不受影响。
- **MP**：配对走 vanilla 先例（`transmitModData`、`syncItemModData`、
  `syncIsoObject`），已在设计上对齐；深度联机场景（双人同时配对同一把遥控器）未做
  并发处理。

```

│   ├── poster.png
│   └── media/
│       ├── scripts/
│       │   ├── items_AutoDoor.txt      # 遥控器/自动门电机/杂志 物品定义
│       │   └── recipes_AutoDoor.txt    # 遥控器+电机制作配方（craftRecipe, 需杂志解锁）
│       ├── textures/                   # 自绘图标 (Item_*.png)
│       └── lua/
│           ├── shared/AutoDoor/AutoDoorDoorLib.lua        # 门识别/链/配对/电量/遥控共享库
│           ├── shared/Translate/{EN,CN}/ItemName.json 等  # 翻译（vanilla 同名文件，按键合并）
│           ├── server/AutoDoor/AutoDoorDistribution.lua   # 杂志战利品（邮箱）
│           └── client/AutoDoor/
│               ├── AutoDoorInstallMenu.lua  # 右键门：安装/重新配对/换电池/移除
│               ├── AutoDoorRemote.lua       # 遥控核心逻辑 + 右键遥控器菜单
│               └── AutoDoorKeybind.lua      # 按键注册（默认 K）+ 按键处理
tools/gen_icons.js   # 图标/poster 生成器（Node，无依赖）

tools/dump_tiles.js  # 原版 tile 属性枚举工具（开发用）
```
